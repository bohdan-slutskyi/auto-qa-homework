# Auto QA Homework

## Назначение

Репозиторий содержит готовые решения домашних заданий по курсу Auto QA.

## Правило README

При добавлении завершённой домашней работы обновляй в том же scope корневой
`README.md`. Для каждого задания указывай:

- номер и название урока;
- путь к папке решения;
- короткое описание результата;
- команду проверки или запуска;
- путь к итоговому артефакту, если он нужен для сдачи.

Перед commit/push сверяй, что README соответствует опубликованным файлам,
команда запуска проверена, а Git scope не включает посторонние изменения.

## Git

Commit и push выполняй только по явному запросу пользователя. Не добавляй
локальные окружения, секреты, cookies, токены и личные данные.
